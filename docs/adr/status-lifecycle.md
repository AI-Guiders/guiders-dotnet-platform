# ADR status lifecycle (Guiders Platform)

Same model as [guiders-fsharp status-lifecycle](https://github.com/AI-Guiders/guiders-fsharp/blob/main/docs/adr/status-lifecycle.md) and [Cascade IDE](https://github.com/KarataevDmitry/cascade-ide/blob/main/docs/adr/status-lifecycle.md).

- **Accepted** — architectural decision adopted.
- **Accepted · Implemented** — decision **and** code/conformance on `main`.
- **Accepted · In progress** — vertical slice shipping; do not mark Implemented until facts pass.

Registry: [adr-registry-v1.md](./adr-registry-v1.md) · [README.md](./README.md).
